# Кабінет словесності — платформа для 5–7 класу

Інтерактивна платформа з уроками української мови. Кожен урок = класна
робота (розігрів → теорія → читання → практика → тест → підсумок) +
окреме домашнє завдання. Один лінк для вас (вчителька), і персональний
лінк для кожного учня — результати всіх видно на одній сторінці.

Зроблено за тим самим принципом, що й «Мій зошит з української» (4–5
клас): статичний сайт на GitHub Pages + безкоштовний Firebase для
збереження результатів.

## Структура репозиторію

```
index.html            — головна учня: вкладки класів (5/6/7), список уроків
login.html             — вхід: персональне посилання або вибір імені зі списку
lessons-6/
  lesson-01.html ... 03.html       — класна робота (готові)
  lesson-01-dz.html ... 03-dz.html — домашні завдання до них
lessons-5/, lessons-7/  — поки порожні, додасте пізніше
teacher/
  index.html            — вчительська панель: теми, учні й посилання, результати
assets/
  style.css             — спільний дизайн (лісово-осіння палітра)
  lesson-engine.js       — рушій класної роботи: кроки, ігри, тест
  lesson-kit.js          — простіші вправи для сторінок ДЗ
  platform.js            — вхід учнів, Firestore, реєстр уроків по класах
  students.js             — запасний (демо) список учнів, якщо Firebase ще не підключено
  firebase-config.js       — ключі вашого Firebase-проєкту + код доступу вчительки
```

## Крок 1. Налаштуйте безкоштовний Firebase

Без цього кроку сайт відкриється, але результати учнів ніде не
збережуться, а панель вчительки буде порожньою.

1. Перейдіть на https://console.firebase.google.com і створіть проєкт.
2. Натисніть значок `</>` («Веб-застосунок»), Firebase покаже об'єкт
   `firebaseConfig` — скопіюйте його значення в `assets/firebase-config.js`
   замість прикладів (`ВАШ_apiKey` і т.д.).
3. У лівому меню: **Build → Firestore Database** → «Create database» →
   будь-який регіон → режим **test mode** (достатньо для приватної групи).
4. У тому ж файлі задайте код доступу до вчительської панелі:
   ```js
   window.TEACHER_PASSCODE = "мій-власний-код";
   ```

## Крок 2. Публікація на GitHub Pages

1. Завантажте цю теку у свій репозиторій на GitHub.
2. **Settings → Pages** → гілка `main`, папка `/ (root)` → зберегти.
3. Сайт буде за адресою `https://<нікнейм>.github.io/<репозиторій>/`.
   Учнівський вхід — на цій адресі. Вчительська панель — за `/teacher/`.

## Крок 3. Додайте учнів

Відкрийте `.../teacher/`, введіть код доступу — і у вкладці «Учні та
персональні посилання» впишіть ім'я та оберіть клас (5/6/7), натисніть
«Додати учня». Список зберігається прямо у Firestore — нічого редагувати
в коді не потрібно. Кнопка «Копіювати» біля кожного учня скопіює його
особисте посилання — надішліть його учневі (Viber, Telegram тощо).
Перейшовши за цим посиланням один раз, учень більше нічого обирати не
буде — воно запам'ятається в його браузері.

Файл `assets/students.js` лишається як запасний демо-список — сайт
покаже його, лише якщо Firebase ще не налаштовано.

## Що бачить учень

- Заходить за своїм персональним посиланням → одразу свій кабінет,
  тільки уроки свого класу.
- У кожного уроку — кнопка «Класна робота» (з іграми, читанням і
  тестом) і окрема кнопка «ДЗ».
- Прогрес (бали за тест, виконання ДЗ) зберігається автоматично й видно
  вам у панелі; можна заходити з будь-якого пристрою під тим самим
  посиланням.

## Що бачить вчителька

- Відкриває `.../teacher/`, вводить код доступу.
- Вкладки класів 5/6/7. У кожній: теми уроків (клік — відкриває урок,
  щоб пояснити його на уроці), список учнів з посиланнями, і таблиця
  результатів — бал за тест і статус ДЗ для кожного учня й уроку.

## Як додати новий урок (наприклад, 4-й для 6 класу)

1. Скопіюйте `lessons-6/lesson-03.html` у `lessons-6/lesson-04.html` і
   `lesson-03-dz.html` у `lesson-04-dz.html`.
2. У `lesson-04.html` замініть увесь вміст функцій `warmupHTML`,
   `theoryHTML`, `readingHTML`, `practiceHTML`, `QUIZ3`, `reflectHTML`
   (і масиви даних над ними) на матеріал нового уроку. Внизу файлу
   змініть `Platform.initLessonPage('l6-04', 'Урок 4. Назва теми')` і
   заголовок/тему в `LessonEngine.init({...})`.
3. У `lesson-04-dz.html` замініть вправи й змініть
   `Platform.initHomeworkPage('l6-04', 'Урок 4. Назва теми')` —
   **ідентифікатор має збігатися** з тим, що в `lesson-04.html`, щоб
   результати тесту й ДЗ потрапляли в один запис учня.
4. Додайте урок у `assets/platform.js`, у масив `Platform.LESSONS['6']`:
   ```js
   { id: 'l6-04', title: 'Урок 4. Назва теми', topic: '§...', file: 'lessons-6/lesson-04.html', dzFile: 'lessons-6/lesson-04-dz.html' }
   ```

## Як почати наповнювати 5 або 7 клас

1. Створіть теки `lessons-5/` або `lessons-7/` за зразком `lessons-6/`.
2. Додайте уроки в `Platform.LESSONS['5']` або `Platform.LESSONS['7']`
   у файлі `assets/platform.js` — так само, як описано вище.
3. Вкладка потрібного класу на головній сторінці й у панелі вчительки
   підхопить нові уроки автоматично.
